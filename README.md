# VYB — Account-Based Link-in-Bio Platform

> **"One identity. One place. One link."**

VYB is an upcoming account-based link-in-bio platform designed for creators, designers, developers, freelancers, musicians, businesses, and students to bring their entire digital presence together into one simple, elegant URL.

**Live Announcement Site:** [getvyb.vercel.app](https://getvyb.vercel.app)

---

## ✦ About VYB

The internet gave us a thousand places to be — Instagram, GitHub, LinkedIn, YouTube, X, portfolios, and blogs. VYB solves identity fragmentation by creating a single, central home for everything you build and share online.

A person creates a VYB account, chooses their username, and gets one clean public URL:

```
getvyb.vercel.app/sagar
```

---

## ✦ Key Features

- **Minimal Announcement Hero**: Clean announcement layout featuring private waitlist access and platform identity details.
- **Editorial Brand Manifesto (`manifesto.html`)**: Dedicated philosophy page detailing the vision behind unified digital presence.
- **Subtle Ivory Light / Dark Theme**: Toggle between luxury dark mode (`#08080A`) and warm ivory light mode (`#F4F0EB`) with persistent `localStorage` preference.
- **Interactive Fluid Canvas**: Real-time ambient background canvas animation (`<canvas id="fluid">`).
- **Pure Web Standards**: Built with pure HTML5, Vanilla CSS, and JavaScript with zero external frameworks or heavy dependencies.
- **Responsive & Accessible**: Fully responsive layout tailored for mobile, tablet, and desktop viewports with reduced-motion support.

## ✦ Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sagarmurkute/link-in-bio-platform.git
   cd link-in-bio-platform
   ```

2. **Open in browser:**
   Open `index.html` directly in any web browser, or serve using VS Code Live Server or python:
   ```bash
   python -m http.server 8000
   ```
