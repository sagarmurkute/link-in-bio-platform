# VYB Design System & Theme Specification

## Color Palette

### Dark Luxury Theme (Default)
- **Background (`--bg`)**: `#08080A` (Deep Obsidian Black)
- **Foreground (`--fg`)**: `#F5F2ED` (Warm Crisp Cream)
- **Secondary Text (`--fg-2`)**: `#E8E2D9` (Warm Soft Off-White)
- **Muted Text (`--muted`)**: `#8E8B88` (Warm Grey)
- **Subtle Muted (`--muted-2`)**: `#4F4D4B` (Dark Charcoal)
- **Borders & Dividers (`--line`)**: `rgba(245, 242, 237, 0.09)`
- **Border Accents (`--line-2`)**: `rgba(245, 242, 237, 0.14)`

### Warm Ivory Light Theme (`[data-theme="light"]`)
- **Background (`--bg`)**: `#F4F0EB` (Warm Subtle Ivory, never stark white)
- **Foreground (`--fg`)**: `#181716` (Deep Charcoal Black)
- **Secondary Text (`--fg-2`)**: `#343230` (Charcoal Grey)
- **Muted Text (`--muted`)**: `#6B6763` (Muted Warm Grey)
- **Borders & Dividers (`--line`)**: `rgba(24, 23, 22, 0.09)`

---

## Typography

- **Serif Font**: `Instrument Serif` (Google Fonts) — Used for large editorial headlines, quote blocks, and main statements.
- **Sans-Serif Font**: `Geist` — Used for body copy, buttons, inputs, and step items.
- **Monospace Font**: `Geist Mono` — Used for kicker tags, URL handles, indexes, status dots, and uppercase labels.
