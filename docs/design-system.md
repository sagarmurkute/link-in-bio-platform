# VYB Official Design System & Color Palette

## Brand Color System

- **Primary Red (`Red 500`)**: `#FF0000` (10% Brand Accent Ratio)
- **Signature Ivory (`Ivory 200`)**: `#FFFFE3` (70% Primary Page Background Ratio)
- **Pure White**: `#FFFFFF` (20% Cards & Input Fill Ratio)
- **Jet Black**: `#000000` (Primary Text & Bold Borders)

## UI Elements & Target Ratios

- **Page Background**: `#FFFFE3` (Signature Ivory)
- **Alternate Section**: `#FF0000` (Primary Red)
- **Cards on Ivory**: `#FFFFFF` (Pure White)
- **Borders**: `#000000` (Jet Black)
- **Dividers**: `#D6D6BE`
- **Input Fill**: `#FFFFFF`
- **Input Focus**: `#FF0000`

**Target Usage Ratio**: `70% Signature Ivory · 20% Pure White · 10% Primary Red`
